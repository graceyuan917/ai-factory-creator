## 新增功能

### 一、3D 资产模型管理

| 功能 | 说明 |
|------|------|
| **模型库分类浏览** | 支持按树形分类结构浏览 3D 资产模型（产线/设备/工厂等分类），提供卡片式视觉展示 |
| **模型详情查看** | 包含 3D 交互式预览、技术参数展示、业务属性列表、文件信息、版本历史 |
| **USD 格式模型上传** | 支持 USD 文件夹/单文件上传，自动解析 USD 结构，提取元数据 |
| **模型元数据录入** | 录入模型编码、名称、分类、技术参数等业务元数据 |
| **模型文件校验** | 自动校验上传文件的格式、大小（≤500MB）、结构完整性 |
| **模型唯一性校验** | 上传时自动检测重复模型，提供覆盖/重命名/取消三种处理方式 |

### 二、工厂项目管理

| 功能 | 说明 |
|------|------|
| **新建工厂项目** | 支持空白创建和从模板创建两种方式，配置项目基本信息（名称/描述/封面） |
| **项目初始化设置** | 配置默认单位、坐标系等基础设计环境参数 |
| **拖拽式布局编辑** | 从模型库拖拽设备/产线模型到 3D 场景，直观布置工厂布局 |
| **布局撤销与重做** | 支持多级操作历史，避免误操作损失 |
| **项目版本管理** | 项目保存时自动创建版本快照，支持版本历史查看 |
| **业务数据绑定配置** | 支持绑定类型选择、字段映射设置、绑定规则定义 |
| **数据校验与冲突解决** | 自动执行绑定数据的完整性/一致性校验，冲突检测与提示，支持手动/自动冲突解决 |

### 三、3D 可视化编辑

| 功能 | 说明 |
|------|------|
| **对象选择** | 单选和多选 3D 场景中的资产实例 |
| **移动/旋转/缩放** | 直观的 Gizmo 工具，拖拽式调整实例的空间位置、方向和尺寸 |
| **多视角查看** | 支持顶视图、前视图、3D 视图等切换 |
| **场景导航** | 场景漫游、缩放、平移，支持 2D/3D 视图切换 |

### 四、3D 资产快捷入口

| 功能 | 说明 |
|------|------|
| **最近使用记录** | 自动记录用户最近使用的模型，在主界面侧边栏快捷展示 |

## 已知问题

| 编号 | 问题描述 | 影响范围 | 规避方案 |
|------|----------|----------|----------|
| KN-001 | 大于 500MB 的 USD 文件上传速度偏慢 | 大模型导入 | 建议分拆为多个子模型上传 |
| KN-002 | 超过 1000 设备实例场景加载帧率下降至 30-35 FPS | 超大场景浏览 | 使用分层视图模式 |
| KN-003 | macOS 平台部分快捷键与系统快捷键冲突 | 操作体验 | 可在设置中自定义快捷键 |
