## 一、产品概述

**AI Factory Creator** 是一款基于 **NVIDIA Omniverse USD Composer** 构建的**工厂 3D 数字孪生布局设计工具**，面向 SMT 制造行业的 IE 工程师和工厂规划师，帮助他们快速完成工厂产线布局的设计、验证和优化。

### 核心价值主张
- **效率提升 80%**：从手工绘图 2-3 天缩短至拖拽式设计 2-3 小时
- **成本降低 40%**：虚拟验证先行，避免物理产线调整的搬迁浪费
- **数据驱动决策**：实时绑定 ERP/MES/WMS 业务数据，实现真正数字孪生

## 三、核心功能

### 3.1 3D 资产模型管理
- **集中化模型库**：统一管理所有设备和产线的 3D 模型（USD 标准格式）
- **智能检索**：按分类、名称、属性等多维度快速查找
- **版本管理**：完整的模型版本历史，支持回滚和比较
- **生命周期管理**：启用/禁用/归档/删除的状态管控

### 3.2 工厂布局设计
- **拖拽式编辑**：直观的 3D 场景操作，无需 3D 建模专业知识
- **多视角查看**：顶视图、前视图、3D 视角自由切换
- **层级管理**：工厂 → 制程 → 产线 → 设备 四层树形结构
- **撤销重做**：多级操作历史，支持试错式设计

### 3.3 业务数据绑定
- **多系统集成**：通过基础数据平台对接 ERP/MES/WMS 业务数据
- **灵活映射**：支持字段级数据映射配置
- **实时校验**：自动检测数据完整性和一致性，冲突提示
- **数字孪生**：业务数据与 3D 场景实时关联，为仿真分析打基础

## 四、技术架构

| 维度 | 说明 |
|------|------|
| **3D 引擎** | NVIDIA Omniverse USD Composer（RTX 实时光线追踪） |
| **3D 标准格式** | USD（Universal Scene Description） |
| **开发框架** | Omniverse Extension + Python/Qt |
| **数据存储** | 本地文件系统（USD）+ SQLite（元数据）+ Redis（缓存） |
| **系统集成** | RESTful API + WebSocket，通过基础数据平台统一对接 |

### 基于 Omniverse 的优势
- 不是从零开发 3D 引擎，而是基于成熟的工业级平台深度定制
- 原生支持 USD 格式，行业标准，可互操作
- RTX 实时光线追踪，1000+ 设备场景流畅渲染
- 插件化架构，支持功能扩展和定制
