## 第一篇：IE 工程师操作指南

### 1.1 快速上手：从零开始设计一个工厂布局

#### 步骤 1：登录系统
1. 启动 AI Factory Creator。
2. 输入用户名和密码登录。
3. 登录后进入「项目仪表板」主界面。

#### 步骤 2：浏览模型库
1. 点击左侧导航栏「模型库」进入。
2. 在分类树中选择「设备」→ 所需设备分类（如 SMT 设备）。
3. 也可在搜索框中输入设备名称或编码进行搜索。
4. 点击模型卡片查看模型详情（3D 预览、技术参数、属性）。

#### 步骤 3：创建工厂项目
1. 点击「项目仪表板」→「新建项目」。
2. 填写项目信息：
   - **项目名称**（必填）：如"烟台工厂 3F-SMT 产线"
   - **项目描述**（选填）：简要说明项目目标
   - **创建方式**：选择「空白创建」或「从模板创建」
3. 点击「创建」进入布局编辑界面。

#### 步骤 4：布置设备实例
1. 在左侧「资产库」面板中展开分类列表。
2. 拖拽设备模型到中央 3D 画布中释放。
3. 基础编辑操作：
   - **移动**：选中实例 → 拖拽箭头（Gizmo）调整位置
   - **旋转**：选中实例 → 拖拽圆环调整方向
   - **缩放**：选中实例 → 拖拽方块调整尺寸
4. 使用工具栏切换视图（顶视图/前视图/3D 视图）以不同角度审视布局。
5. 操作错误时可点击「撤销」（Ctrl+Z）回退。

#### 步骤 5：管理工厂层级
1. 在左侧「工厂树」面板中查看层级结构。
2. 右键节点可添加子节点（制程 → 产线 → 设备）。
3. 点击节点在右侧属性面板中编辑节点属性。

#### 步骤 6：数据绑定
1. 在工厂树中选中需要绑定的节点（制程/产线/设备）。
2. 在右侧面板找到「业务数据绑定」分组。
3. 点击「绑定业务数据」按钮，选择绑定类型。
4. 使用搜索功能查找业务系统中的对应数据记录。
5. 配置字段映射关系。
6. 点击「保存绑定」→ 系统自动执行数据校验。
7. 校验通过后，节点显示绿色「已绑定」状态。

#### 步骤 7：保存与版本管理
1. 操作过程中系统每 5 分钟自动保存一次。
2. 可随时点击「保存」按钮手动保存，保存时自动创建版本快照。
3. 在「版本历史」中查看所有版本记录，支持版本回滚。

### 1.2 常见问题

**Q：拖拽设备时找不到想要的模型？**
A：先检查模型库中是否已上传该设备模型。如未上传，联系 U3D 工程师（模型管理员）上传。

**Q：数据绑定时搜索不到业务数据？**
A：确认（1）基础数据平台连接已配置，（2）所选绑定类型字段映射已配置。联系系统管理员检查接口状态。

**Q：3D 场景操作卡顿？**
A：尝试切换到顶视图（2D）模式，或减少画布中同时显示的元素数量。在大场景下建议使用分层查看。

## 第二篇：系统管理员操作指南

### 2.1 用户与权限管理

#### 添加新用户
1. 进入「系统管理后台」→「用户管理」。
2. 点击「添加用户」。
3. 填写用户信息：用户名、姓名、邮箱、所属部门。
4. 选择角色（IE 工程师 / 工厂规划师 / 3D 模型工程师 / 管理员）。
5. 点击「保存」完成添加。

#### 配置角色权限
1. 进入「系统管理后台」→「角色管理」。
2. 选择目标角色，查看/编辑该角色的权限模板。
3. 权限分为：模型管理权限、项目管理权限、数据绑定权限、系统管理权限。
4. 保存后角色下所有用户权限生效。

### 2.2 系统配置管理

#### 基础参数配置
1. 进入「系统管理后台」→「系统配置」。
2. 可配置项包括：文件上传大小限制、默认单位制、场景渲染质量、自动保存间隔。
3. 修改后点击「保存」即时生效。

#### 字典数据管理
1. 进入「系统管理后台」→「字典管理」。
2. 管理资产类型分类树、状态枚举值、业务属性模板等字典数据。
3. 支持新增/修改/删除/导入导出。

### 2.3 部署与维护

#### 环境部署
1. 确保目标机器安装 NVIDIA Omniverse Launcher。
2. 安装 Omniverse Kit 105+ 版本。
3. 将 AI Factory Creator 扩展包放入 Omniverse 扩展目录。
4. 启动 Omniverse，在扩展管理器中启用 AI Factory Creator。

#### 基础数据平台连接配置
1. 进入「系统管理后台」→「集成配置」。
2. 填写基础数据平台连接参数（URL、认证信息）。
3. 点击「连接测试」验证连通性。
4. 配置数据同步策略（同步频率、范围）。

## 第三篇：实施人员指南

### 3.1 安装部署流程

1. **环境检查**：确认服务器/工作站满足最低硬件配置要求（详见 Release Notes 系统要求）。
2. **Omniverse 安装**：按 Omniverse 官方文档完成安装。
3. **扩展安装**：将 AI Factory Creator 扩展包解压到 `omniverse/extensions/` 目录。
4. **依赖检查**：确认 Python 3.9+、SQLite、Redis 等依赖组件就绪。
5. **启动验证**：启动 Omniverse，在扩展管理器中确认 AI Factory Creator 加载成功。

### 3.2 初始数据导入

1. **资产类型分类**：在系统管理后台→字典管理中导入分类树（或通过批量导入功能）。
2. **3D 模型**：通过模型库上传功能批量导入现有设备 USD 模型。
3. **用户批量导入**：通过用户管理→导入功能批量创建用户账号。

### 3.3 常见实施问题

**Q：Omniverse 版本不兼容？**
A：AI Factory Creator 当前基于 Omniverse Kit 105+。如使用更高版本，需确认 API 兼容性，必要时联系开发团队获取适配版本。

**Q：部署后用户无法连接？**
A：确认网络防火墙未拦截 Omniverse 服务端口。检查基础数据平台连接配置是否正确。
